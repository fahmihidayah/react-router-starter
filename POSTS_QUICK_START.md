# Posts quick start

Run the app with `pnpm dev`, sign in as an administrator, and open `/admin/posts`.

- Create content at `/admin/posts/new`.
- Edit an item from `/admin/posts/:id`.
- Review public output at `/posts` and `/posts/:slug`.

Code locations and safety checks are summarized in
[`POSTS_FEATURE_GUIDE.md`](./POSTS_FEATURE_GUIDE.md). Repository-wide architecture and verification
rules live in [`AGENTS.md`](./AGENTS.md).
